InternHub – Responsive Internship Board

Project Description

InternHub is a responsive internship listing website that helps students explore internship opportunities based on their interests and skills.

Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON

Features

- Responsive design for mobile, tablet and desktop
- Internship listing cards
- Search by company name or job role
- Filter internships by domain
- Empty search results message
- Error handling
- Accessible form labels and keyboard navigation

Live Website

GitHub Repository

Open the project using VS Code and run index.html with Live Server.
